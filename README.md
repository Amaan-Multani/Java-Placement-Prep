## 🔑 Key Concepts Learned

- ✅ JVM working — why `public static void main(String[] args)`
- ✅ `println` vs `print` vs `\n`
- ✅ Integer division trap — `5/9 = 0` vs `5.0/9.0 = 0.55`
- ✅ Boundary conditions — `>= 18` not `> 18`
- ✅ Switch `break` and fall-through behavior
- ✅ Scanner resource leak — always `sc.close()`
- ✅ `=` (assignment) vs `==` (comparison) — classic bug
- ✅ while vs do-while — when does the body execute first?
- ✅ Prime check — boolean flag + loop + early `break`
